# 🎮 Bingo Elite - Multiplayer Bingo Game

A real-time multiplayer Bingo game built with Node.js, Socket.io, and MongoDB.

## 🚀 Features

- **Real-time multiplayer** Bingo gameplay
- **Four stake rooms**: Bronze (10 ETB), Silver (20 ETB), Gold (50 ETB), Elite (100 ETB)
- **Admin dashboard** for game management
- **Four Corners Bonus**: +50 ETB bonus for special win
- **Persistent data storage** with MongoDB
- **Telegram Web App** compatible
- **Mobile-responsive** design

## 📋 Prerequisites

- Node.js (v14 or higher)
- MongoDB Atlas account (free tier works)
- Basic understanding of terminal/command line
